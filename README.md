## Requirements
JDK 11 or newer (`java -version`, `javac -version`). Bash scripts: Linux, macOS, or WSL / Git Bash on Windows.

## Build and run

Linux / macOS / WSL:
```bash
scripts/run.sh build            # compile into bin/
scripts/run.sh server 5000      # terminal 1
scripts/run.sh client localhost 5000   # terminal 2, 3, ...  (console client)
scripts/run.sh gui              # or the GUI client
```

Windows (cmd / PowerShell), no bash needed:
```
javac -encoding UTF-8 -d bin @sources.txt
java -cp bin ChatServer 5000
java -cp bin ChatClient localhost 5000
java -cp bin ChatGUI
```

The server prints its own LAN addresses at start-up.

## Connecting several PCs to one server
1. Pick one PC as the server, start it: `scripts/run.sh server 5000`. Note the address it prints (e.g. `192.168.1.20`), or run `ip a` / `ipconfig`.
2. All PCs must be on the same network (same Wi-Fi / LAN).
3. Allow port 5000 in the server PC's firewall (Linux: `sudo ufw allow 5000/tcp`; Windows: allow Java / port 5000 in Windows Defender Firewall).
4. On every other PC: `java -cp bin ChatClient 192.168.1.20 5000` (or open the GUI and type the server IP in the host box).
5. Register or log in. Two clients on one PC also work with `localhost`.

## Chat commands (console client)
| Command | What it does |
|---|---|
| `text` | message to everyone |
| `/msg <user> <text>` | private message |
| `/g <group> <text>` | message to a group |
| `/group create <name>` / `join` / `leave` | manage groups |
| `/group list` / `/group mine` / `/group members <name>` | list all groups / your groups / members |
| `/users` | who is online |
| `/history [n]` | last n stored messages (1-200) |
| `/echo off` | do not show your own messages again |
| `/help`, `/quit` | help, exit |

## GUI
Click a person or a group in the left lists to choose who you are writing to (shown in the header; "Everyone" returns to public chat). Just type text and press Enter - the GUI adds `/msg` or `/g` for you, so no commands appear in the input box. Buttons create, join and leave groups.

## Tests
```bash

```

## Profiling
Simple profiler (like gprof's flat profile): calls, total time and average time of each server method.
```bash
scripts/profile.sh              # starts server with -Dprofile=true, runs the load test, prints the table
```
Result is saved in `docs/profiling/profile.txt`. Details: [docs/PROFILING.md](docs/PROFILING.md).

## Report
`scripts/run.sh docs` builds `docs/report/report_ieee.pdf` (needs pdflatex).
